どちらも呼吸をしながら体を動かします。

見た目が似ているので混同されがちですが、**目的が違います。**

## ざっくり言うと

| | ヨガ | ピラティス |
|---|---|---|
| 大切にすること | 呼吸と心身のリラックス | 体の使い方を整える |
| 動き方 | ポーズを保つ時間が長い | 動き続けることが多い |
| 呼吸 | 腹式呼吸が中心 | 胸式呼吸が中心 |
| 終わったあと | 静かに落ち着く | 体の内側が目覚めている |

ヨガが「ゆるめる」方向だとすれば、ピラティスは「使う」方向です。

## 呼吸が違います

ヨガでは、お腹をふくらませる**腹式呼吸**を使うことが多くなります。

ピラティスでは、**胸式呼吸**を使います。お腹は締めたまま、肋骨を広げて息を入れます。

お腹を締めたまま動き続けるためです。理由については[ピラティスの胸式呼吸とは](/blog/pilates-kokyuu/)でご説明しています。

## 成り立ちが違います

ヨガは、インドで生まれた長い歴史を持つものです。

ピラティスは、**リハビリの考え方から生まれました。** 20世紀に入ってからのもので、負傷した方の回復を支えるところから始まっています。

## どちらを選ぶか

目安としては、こう考えてください。

| | |
|---|---|
| リラックスしたい・頭を休めたい | ヨガ |
| 姿勢を整えたい・体幹を使いたい | ピラティス |
| 柔軟性を上げたい | どちらでも |
| 体がかたくて不安 | ピラティス（マシンが支えてくれます） |

> どちらが優れている、という話ではありません。両方通われている方も多くいらっしゃいます。

## 当スタジオはマシンピラティス専門です

リフォーマーを**お一人につき1台**使用します。

マシンのバネが動きを支えてくれるので、自分の力だけで姿勢を保つ必要がありません。体がかたい方、運動が苦手な方にも入りやすい形です。

最大8名の少人数制で、インストラクターは全員が指導資格を保有しています。

## ヨガもやりたい方へ

同じ三幸ビルの3階に、ヨガスタジオ「**LOHAS LOHAS Studio**」があります。

常温ヨガ・ホットヨガを行っています。

## よくある質問

### ピラティスとヨガ、どちらが初心者向けですか？

どちらも初めての方が始められます。体がかたいことが不安な方には、マシンが支えてくれるマシンピラティスが入りやすいと言われます。

### 両方通ってもいいですか？

問題ありません。目的が違うので、組み合わせて通われる方も多くいらっしゃいます。

### 呼吸は何が違いますか？

ヨガは腹式呼吸、ピラティスは胸式呼吸が中心です。ピラティスではお腹を締めたまま動くため、肋骨を広げる呼吸を使います。
