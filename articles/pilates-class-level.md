予約ページを開くと、クラス名がいくつも並んでいます。

はじめての方は、ここで止まってしまうことがあります。

**結論からお伝えすると、BASIC 1 からで大丈夫です。**

## クラスは2種類に分かれます

当スタジオのグループレッスンは、使うマシンで2つに分かれます。どちらも60分、最大8名、お一人につき1台です。

### リフォーマークラス

腹筋・背中・肩・お尻・骨盤底筋を使いながら、体幹をバランスよく働かせるクラスです。

| クラス | 内容 |
|---|---|
| BASIC 1 | 基礎エクササイズを丁寧に。はじめての方はこちら |
| BASIC 1.5 | BASIC 1より少しチャレンジングに、テンポよく |
| FLOW 1.5 | 基礎の上に応用エクササイズを積み重ねます |
| FLOW 2 | バランスとコントロールを重視したハイテンポクラス |

膝・股関節・腰まわりに不安のある方は、事前に医師へご相談のうえ、インストラクターへお伝えください。

### タワークラス

スプリングとバーを使い、**リハビリ由来の丁寧な動き**で、左右のバランス・背骨の柔軟性・深層筋の活性化を促します。

| クラス | 内容 |
|---|---|
| BASIC 1 | 安全に、基礎からしっかりと |
| BASIC 1.5 | 強度を上げてステップアップ |

ご年配の方や、身体の状態に配慮しながら取り組みたい方にもご利用いただけます。

## どちらから始めるか

テンポよく動きたい、体幹から整えたい → **リフォーマーの BASIC 1**

丁寧に動きたい、身体の状態に不安がある → **タワーの BASIC 1**

迷われたら、リフォーマーの BASIC 1 からで問題ありません。

## ステップアップのしかた

BASIC 1 → BASIC 1.5 → FLOW 1.5 → FLOW 2 の順に進めます。

いつ上げるかに決まりはありません。「物足りない」と感じたときが目安です。インストラクターに相談していただければ、今の状態に合うクラスをご案内します。

**同じレベルのまま通い続けても構いません。** 基礎を丁寧に続ける方もいらっしゃいます。

## よくある質問

### はじめてはどのクラスを選べばいいですか？

BASIC 1 からのスタートをおすすめしています。基礎エクササイズを丁寧に行うクラスです。慣れてきたら BASIC 1.5、FLOW 1.5、FLOW 2 とステップアップいただけます。

### タワークラスとリフォーマークラスの違いは何ですか？

リフォーマークラスは体幹をバランスよく働かせ、姿勢や身体の動きを整えるクラスです。タワークラスはスプリングとバーを使い、リハビリ由来の丁寧な動きで左右のバランスや背骨の柔軟性、深層筋の活性化を促します。

### レッスンは何分ですか？

60分です。最大8名の少人数制で、リフォーマーはお一人につき1台お使いいただきます。
