職場の近くで探すか、家の近くで探すか。

中央線沿線にお住まいか、お勤めの方は、その中間という選び方もできます。

## 中央線での距離

当スタジオは**阿佐ヶ谷駅から徒歩約5分**。三幸ビルの2Fです。

| | |
|---|---|
| 新宿から | 中央線で約10分 |
| 東京駅から | 30分ほど |
| 高円寺・荻窪から | 一駅 |

中野からも中央線で数分です。丸ノ内線をお使いの場合は、**南阿佐ヶ谷駅からも徒歩約5分**です。

## 仕事帰りに寄る場合

平日の営業は**21:30まで**です（火〜金 9:30〜21:30）。

新宿で19時に仕事が終われば、移動10分＋徒歩5分で、十分間に合います。

| | |
|---|---|
| 火〜金 | 9:30〜21:30 |
| 土日 | 8:00〜17:00 |
| 定休日 | 月曜 |

## 職場の近くより、通り道のほうが続きます

スタジオ選びでよくある失敗が、**職場のすぐ近くで選ぶこと**です。

残業した日や、予定が入った日に行けなくなります。帰り道の途中にあるほうが、「今日は寄っていこう」が成立しやすくなります。

逆に、家から遠すぎてもだめです。休日に行く気になりません。

## 予約は24時間受け付けています

オンライン予約は24時間対応で、**空き枠があれば当日のご予約も可能**です。

「今日は早く終わりそう」というときにも使えます。空き状況は予約ページでその場で確認できます。

## 手ぶらでも大丈夫です

着替えを忘れても、ウエア上下 各¥100、タオル ¥150でレンタルがあります。

レッスン後に汗を流したい場合は、同じ建物の東京岩盤浴でシャワーをご利用いただけます（30分¥300・アメニティ・バスタオル付）。

## よくある質問

### 新宿から阿佐ヶ谷まではどのくらいですか？

中央線で約10分です。阿佐ヶ谷駅から当スタジオまでは徒歩約5分です。

### 仕事帰りに間に合いますか？

平日（火〜金）は21:30まで営業しています。土日は8:00〜17:00、月曜定休です。

### 手ぶらで行っても大丈夫ですか？

大丈夫です。ウエア上下を各¥100、タオルを¥150でレンタルしています。
