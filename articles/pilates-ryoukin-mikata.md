月会費だけを並べても、高いのか安いのか分かりません。

**1回あたりいくらになるか**に直すと、比べやすくなります。

## 通うペースから逆算する

| 通うペース | プラン | 1回あたり |
|---|---|---|
| 週1回（月4回） | マンスリー4 ¥13,310 | 約¥3,330 |
| 週2回（月8回） | マンスリー8 ¥21,780 | 約¥2,720 |
| 月12回以上 | フリープラン ¥32,670 | 約¥2,720〜 |

月12回以上通いたい方には、フリープランがおすすめです。

**マンツーマンの場合**

| | 料金 | 1回あたり |
|---|---|---|
| マンスリー2（月2回） | ¥18,150 | ¥9,075 |
| 都度利用 プライベート60 | ¥9,680 | ¥9,680 |

月2回以上使うなら、**マンスリー2のほうが1回あたり約¥600お得**です。

## 月会費以外にかかるもの

ここを見落とすと、思っていた金額と変わってきます。

| | |
|---|---|
| 入会金 | ¥11,000 → **体験当日のご入会で¥0** |
| 登録料 | ¥3,300 → **体験当日のご入会で¥0** |
| 施設利用料 | ¥550／月 |

**体験当日にご入会いただくと、入会金・登録料・1ヶ月分の月会費が0円**になります。

とはいえ、その場で決めていただく必要はありません。持ち帰ってご検討いただけます。

## よくある質問

### 月会費のほかにかかる費用はありますか？

月額の施設利用料¥550（税込）を別途頂戴しております。入会金¥11,000と登録料¥3,300は、体験当日のご入会で0円になります。

### どのプランを選べばいいですか？

週1回ペースならマンスリー4（¥13,310）、週2回ペースならマンスリー8（¥21,780）が目安です。月12回以上通われる場合は、1回あたりの金額がフリープラン（¥32,670）のほうが安くなります。

### 支払い方法は何が使えますか？
