はじめての方に、中で何が起きているかをお伝えします。

## 入ってから出るまで

| | |
|---|---|
| 10分前 | 到着・着替え |
| 開始 | 体の状態を聞く（痛いところ、気になるところ） |
| 最初の10分 | 呼吸と、背骨を動かすところから |
| 中盤 | マシンでの動き。脚・体幹・腕 |
| 最後の5分 | ゆるめて、整える |
| 終了後 | 次回の予約・質問 |

## いきなり動かしません

**最初の10分がいちばん大事**です。

呼吸を整えて、背骨を1本ずつ動かす。ここを飛ばすと、そのあとの動きが雑になります。

## 一人ずつバネの重さが違います

同じ動きでも、**バネの本数と強さは一人ずつ変えます。**

隣の人と同じにする必要はありません。むしろ、同じだと誰かに合っていません。

> 「軽くしてもらった」のは手を抜いているのではなく、**その人に合わせた**ということです。

## 止めても構いません

痛い、きつい、分からない。

**途中で止めてください。** 無理に続けても、体が守りに入って別の場所が働きます。意味がありません。

## 終わったあと

息は上がりません。汗は少しかきます。

**そのまま出かけられる**方がほとんどです。[シャワーのこと](/blog/pilates-shower/)もご覧ください。

## よくある質問

### レッスンはどう進みますか？

呼吸と背骨を動かすところから始めて、マシンでの動きに入り、最後にゆるめて終わります。いきなり強い動きはしません。

### 途中で止めてもいいですか？

止めてください。痛みや違和感があるときに続けると、別の場所が代わりに働いてしまいます。
