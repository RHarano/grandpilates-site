杉並区は、中央線と丸ノ内線が通っている区です。

阿佐ヶ谷・高円寺・荻窪・西荻窪・南阿佐ヶ谷・新高円寺。駅が多いぶん、どこに通うか迷いやすい場所でもあります。

## 当スタジオの場所

| | |
|---|---|
| 所在地 | 東京都杉並区阿佐谷南1-36-4 三幸ビル 2F |
| アクセス | JR中央線・総武線「阿佐ヶ谷駅」から徒歩約5分 |
| | 東京メトロ丸ノ内線「南阿佐ヶ谷駅」から徒歩約5分 |
| 電話 | 03-3311-8211 |

**2路線が使える**ので、お住まいや職場の位置によって経路を選べます。

## 「通いやすさ」がいちばん効きます

スタジオ選びでは、内容や料金に目が行きがちです。

ただ、続かなくなるいちばんの理由は**通うまでが遠いこと**です。仕事帰りに寄り道が必要だと、疲れている日は飛ばします。1回飛ばすと、次も飛ばしやすくなります。

高円寺・荻窪からは一駅。南阿佐ヶ谷からも徒歩約5分です。

## 杉並区内から通われている方

実際に多いのは、阿佐ヶ谷・南阿佐ヶ谷・高円寺・荻窪にお住まいか、職場が中央線沿線という方です。

新宿から中央線で約10分、東京駅からでも30分ほど。**勤め先からの帰り道**に組み込む形で通われる方もいらっしゃいます。

## よくある質問

JR中央線・総武線「阿佐ヶ谷駅」から徒歩約5分です。東京メトロ丸ノ内線「南阿佐ヶ谷駅」からも徒歩約5分です。高円寺・荻窪からも一駅の距離です。

火〜金は9:30〜21:30、土日は8:00〜17:00です。月曜定休です。
