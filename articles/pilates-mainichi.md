通い始めて感覚がつかめてくると、「もっと行きたい」となる方がいます。

当スタジオには**回数無制限のフリープラン**があるので、仕組みのうえでは毎日通えます。

## ただ、最初から毎日である必要はありません

はじめの数回は、身体に張りが出ます。普段使っていない場所が働くからです。

張りが残っているあいだに詰め込んでも、集中して動けません。**まずは週1回、慣れてきたら週2回**。この順番で増やす方がほとんどです。

## 回数と金額の関係

| 通うペース | プラン | 1回あたり |
|---|---|---|
| 月4回（週1回） | マンスリー4 ¥13,310 | 約¥3,330 |
| 月8回（週2回） | マンスリー8 ¥21,780 | 約¥2,720 |
| 月12回以上 | フリープラン ¥32,670 | 約¥2,720〜 |

**月12回を超えるあたりから、フリープランのほうが1回あたり安くなります。** 逆に言えば、それ未満ならマンスリー8で足ります。

## いちばんもったいないのは「行けなかった月」

週2回のつもりで契約して、月2回しか行けなかった。

これがいちばんもったいないパターンです。金額に対して損をした気持ちになり、その気持ちが続くと、通うこと自体が面倒になります。

少なめから始めて、足りなければ増やす。この順番のほうが続きます。

## クラスを変えるという通い方もあります

同じクラスばかりでなくても構いません。

| | クラス |
|---|---|
| リフォーマー | BASIC 1 / BASIC 1.5 / FLOW 1.5 / FLOW 2 |
| タワー | BASIC 1 / BASIC 1.5 |

テンポの速い FLOW と、丁寧に動くタワーを組み合わせる方もいらっしゃいます。

## よくある質問

### ピラティスは毎日通ってもいいですか？

回数無制限のフリープラン（¥32,670／月）をご用意しているので、仕組みのうえでは毎日通えます。ただし、はじめのうちは身体に張りが出るため、週1回から始めて慣れてきたら増やす方がほとんどです。

### フリープランはいつから得になりますか？

月12回以上ご利用の場合、1回あたり約¥2,720となり、マンスリー8と同等以下になります。月12回を目安にお考えください。

### プランは途中で変えられますか？

通うペースに合わせてご相談いただけます。体験当日にその場でご入会いただく必要はありませんので、まず一度動いてみてからお決めください。
